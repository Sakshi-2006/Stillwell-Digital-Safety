---
name: Self-reported assessment scope
description: Project boundary for how social-media privacy assessments collect and process data.
---

The assessment must stay questionnaire-only and self-reported. Do not scrape profiles, import profile exports, profile real people, or ask for sensitive identifying values or private message content. Keep synthetic analytics separate from individual assessment results.

**Why:** The project brief sets a defensive privacy boundary: no scraping or real-person profiling, and no unnecessary personal information.

**How to apply:** New assessment features should accept only enumerated choices about the user's own settings and habits. Persist derived summaries only, not raw answers or identity details.
